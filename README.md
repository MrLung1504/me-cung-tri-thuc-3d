# Mê Cung Tri Thức 3D

Game mê cung góc nhìn thứ nhất (POV 3D) học tập cho học sinh THCS (khối 6–9), theo chương trình Kết nối tri thức (GDPT 2018).

## Cách chơi

- **Di chuyển:** phím WASD / mũi tên (máy tính), joystick ảo (điện thoại). **Nhìn quanh:** giữ chuột trái và kéo (máy tính), vuốt nửa phải màn hình (điện thoại).
- Trong mê cung có các vật dụng học tập: chạm vào để mở câu hỏi trắc nghiệm hoặc Đúng/Sai thuộc 8 môn (Toán, KHTN, Ngữ Văn, Sử – Địa, Tiếng Anh, Tin học, Công nghệ, GDCD).
- **Trả lời đúng:** +10 điểm, tặng ngẫu nhiên 1 kỹ năng. **Trả lời sai:** −5 điểm, +5 giây phạt.
- Tìm đường ra **cổng thoát** càng nhanh càng tốt — bảng xếp hạng theo tổng thời gian (càng ngắn càng cao).
- **Cửa hàng kỹ năng** ở đầu mỗi màn (tối đa 2 kỹ năng/màn): xem bản đồ, vệt sáng, la bàn, tăng tốc, đóng băng thời gian, xuyên tường.

## Tính năng

- 10 màn mê cung (9×9 đến 29×29), sinh ngẫu nhiên bằng thuật toán Recursive Backtracking.
- Ngân hàng 6.400 câu hỏi (8 môn × 4 khối), đã kiểm chứng theo sách giáo khoa Kết nối tri thức.
- Tài khoản học sinh/giáo viên, lưu tiến độ, bảng xếp hạng theo khối, đồng bộ qua Firebase.
- Trang Quản trị: sửa ngân hàng câu hỏi, quản lý tài khoản, xem "Lời Bác dạy".

## Chạy game

Mở file `index.html` bằng trình duyệt (khuyên dùng Chrome), hoặc chơi qua GitHub Pages sau khi bật Pages cho repo này.

## Công nghệ

HTML5 / CSS3 / JavaScript + Three.js. Toàn bộ game nằm trong một file `index.html` duy nhất.
